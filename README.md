# แผนที่มิเตอร์ไฟฟ้า–น้ำประปา (meter-map)

เว็บแสดงจุดมิเตอร์ไฟฟ้าและประปาบนแผนที่ดาวเทียม 3 มิติ พร้อมแนวท่อ อาคารแยกสีตามหน่วยที่รับผิดชอบ และกราฟการใช้รายเดือน ทำขึ้นให้ผู้ตรวจมาตรการประหยัดพลังงาน (จบ.) ของ ม.๑ พัน.๓ รอ. ใช้งาน แต่หน่วยงานอื่นนำไปตั้งใช้กับพื้นที่ของตัวเองได้

**ลองใช้ (ข้อมูลสมมติ):** https://intakaew.github.io/meter-map/?demo — รหัสทดลอง ผู้ดูแล 9999 · กองร้อย 1111–5555

**ใช้งานจริง:** ระบบของหน่วยอยู่หลังด่านยืนยันตัวตนอีกชั้น เปิดได้เฉพาะผู้ได้รับอนุญาต (ลิงก์เดิมจะพาไปเอง)

> **ข้อมูลในโค้ดชุดนี้เป็นค่ายสมมติทั้งหมด** วางไว้กลางทุ่งนา ไม่ใช่ผัง แนวท่อ หรือพิกัดของหน่วยจริง ข้อมูลจริงของหน่วยเก็บอยู่ใน Google Sheet/Drive ของหน่วยเท่านั้น และไม่อยู่ใน repo นี้

**พัฒนาโดย:** Wirunwatcha Intakaew ([@intakaew](https://github.com/intakaew))

## ความสามารถ

- **แผนที่ 3D:** ใช้ MapLibre GL กับภาพดาวเทียม Esri อาคารยกเป็น 3 มิติแยกสีตามกองร้อย แสดงแนวท่อเมนกับท่อแยกเข้าอาคาร ระบบช่วยวางท่อแยกให้อัตโนมัติ
- **สิทธิ์ 3 ชั้น**
  1. ผู้ตรวจและผู้ชมทั่วไปดูแผนที่และกราฟได้อย่างเดียว ถ้าผู้ดูแลตั้ง **รหัสเข้าดู** ต้องใส่รหัสนั้นก่อน (ไม่ต้องสมัครบัญชี)
  2. ผู้กรอกข้อมูลของแต่ละหน่วย กรอกเลขมิเตอร์และแนบรูปหน้าปัดได้เฉพาะของหน่วยตัวเอง และเฉพาะเดือนที่เปิดรอบ
  3. ผู้ดูแลจัดการได้ทุกอย่าง
- **สมัครใช้งานและอนุมัติ:** ผู้ใช้สมัครเอง ผู้ดูแลอนุมัติและกำหนดหน่วยให้ ระงับสิทธิ์หรือเปลี่ยนสิทธิ์แล้วมีผลทันที
- **ข้อมูลต่อเนื่องหลายปี:** ดูการใช้เป็นรายปีงบประมาณ และเลือกเปรียบเทียบข้ามปีหรือข้ามหน่วยได้เอง
- **QR โค้ด:** ติดที่มิเตอร์แต่ละลูก สแกนแล้วเปิดหน้ามิเตอร์นั้นทันที
- **ที่เก็บข้อมูลฟรี:** เก็บใน Google Sheet และ Google Drive ผ่าน Google Apps Script ผู้ดูแลเปิดชีตดูหรือแก้ตัวเลขได้ตรง ๆ
- **ส่งมอบงาน:** สำรองข้อมูลเป็นไฟล์ และส่งต่อบัญชีให้ผู้รับงานคนใหม่ได้
- **ใช้ได้ทุกจอ:** ภาษาไทยทั้งหมด มีโหมดสว่างและมืด ใช้บนมือถือได้

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บทั้งหมดอยู่ในไฟล์เดียว ค่า `GAS_URL` บนสุดของสคริปต์คือลิงก์เว็บแอป Apps Script ถ้าเว้นว่างจะเป็นโหมดต้นแบบที่เก็บข้อมูลในเบราว์เซอร์ |
| `google/Code.gs` | ตัวกลางบน Google Apps Script ดูแลสิทธิ์ โทเค็น บัญชีผู้ใช้ ชีต และรูป |
| `dev/gas-mock.mjs` | Google จำลองสำหรับทดสอบในเครื่อง |
| `dev/test-gas.mjs` | ชุดทดสอบตัวกลาง 54 ข้อ รันด้วย `node dev/test-gas.mjs` |
| `INSTALL.md` | วิธีติดตั้งกับบัญชี Google ของคุณเอง |

## ความปลอดภัยโดยสรุป

- **รหัสเข้าดู:** ผู้ดูแลตั้งรหัสเองในหน้าผู้ดูแล เมื่อตั้งแล้ว ตัวกลางไม่ส่งข้อมูลใด ๆ ให้ผู้ที่ยังไม่ได้ใส่รหัส (ไม่ใช่แค่หน้าบังตา) เครื่องที่ใส่รหัสแล้วจำไว้ 30 วัน เปลี่ยนรหัสเมื่อไร ทุกเครื่องต้องใส่รหัสใหม่
- **ข้อมูลที่ส่งให้ผู้ชม:** ตัดรหัสออกทั้งหมด และไม่มีข้อมูลบัญชีผู้ใช้
- **รหัสผ่าน:** เก็บเป็นค่าแฮช SHA-256 ใส่เกลือ วนซ้ำ อ่านย้อนเป็นรหัสจริงไม่ได้
- **ตรวจสิทธิ์ฝั่งเซิร์ฟเวอร์ทุกคำขอ:** เช็กว่าเป็นหน่วยไหน เดือนไหน และบทบาทอะไร
- **กันเดารหัส:** ถ้ามีการใส่รหัสผิดเกิน 50 ครั้งใน 10 นาที ระบบพักการเข้าสู่ระบบ และจำกัดจำนวนการสมัครต่อช่วงเวลา
- **กันเขียนทับ:** ใช้เลขเวอร์ชันกันการบันทึกทับกันเมื่อแก้จากหลายเครื่องพร้อมกัน
- **ด่านตัวส่งต่อ (ไม่บังคับ):** ตั้งพร็อพเพอร์ตี `PROXY_KEY` ใน Apps Script แล้วตัวกลางจะรับเฉพาะคำขอที่มีกุญแจนี้ เหมาะกับการวางหน้าเว็บหลังด่านยืนยันตัวตน (เช่น Cloudflare Access) แล้วให้ตัวส่งต่อแนบกุญแจให้ ใครเรียกลิงก์ Apps Script ตรง ๆ จะได้ 403
- **กันสูตรในชีต:** ข้อความจากผู้ใช้ที่ขึ้นต้นด้วย = + - @ ถูกบันทึกเป็นข้อความ ไม่ถูกตีเป็นสูตร
